# 动物医学教学PPT智造团（Vet-Med Teaching PPT Team）

五人专家团把任意动物医学教学主题做成证据核验、教学对齐、可直接投影授课的完整PPT方案与页面内容，全程六阶段门控、human-in-the-loop确认。

## 类型

Team 型（多角色协作团队）

## 六阶段门控流水线

阶段0任务冻结澄清 → 阶段1教学蓝图 → 阶段2证据核验（Ima知识库+联网ReAct）→ 阶段3页面级教学设计 → 阶段4迭代修订（快速通道）→ 阶段5制作交付。

门控允许合并：阶段0+1可合并确认，阶段4小改动走快速通道；阶段1蓝图与阶段3页面脚本的确认权永远保留给用户。

## Ima 知识库路由

默认挂载7个动医知识库（《禽病》主力库/《猪病》/《牛羊病》/《伴侣动物疾病》/病毒学-免疫学-细胞学/流感/动物疫病诊断技术WOAH-FAO-WHO），每次任务按主题选1-3个最相关库调用，禁止全库齐搜。UpNote个人笔记为运行时探测通道，不可用直接跳过。

- 帮我把《禽流感》这一章做成2课时的教学PPT，受众是动物医学职业本科大二学生
