# 教学设计要求（Pedagogical Design Requirements · 判据封装层）

## 定位（先读这段）

- 本 skill 是 vet-med-ppt-team 专家团包的**判据触发封装**：识别"这件事需要过教学设计判据"，
  然后把执行方引到判据源。
- **判据唯一权威源（SSOT）= 包内 `references/pedagogical-rubric.md`**——
  本文件与该文件的关系是「引用 ≠ 复制」：判据内容、阈值、实证锚点一律以量规为准，
  本文件只在量规变更时同步引用口径。**两处同时写判据 = 判据单一源纪律被破坏**。
- **铁律：只作判据，不作内容来源。** 学科事实来自证据链（dvm-content-expert），
  本 skill 不提供任何知识点。

## 触发条件（何时启用本 skill）

任一命中即启用：
1. 用户或成员提出「教学设计 / 认知负荷 / 信息密度 / 教学重构 / 反向设计 / 学习目标对齐」；
2. 闸2 设计确认前，蓝图（pedagogy-architect）自检；
3. Loop B 检查模式产出教学设计维诊断；
4. 重构模式 L2（教学级）重排教学路径——**必须**过 §2 三件套对齐；
5. 培训类受众接单（§3 额外启用）。

## 调用契约（怎么用）

1. **判据查询**：按需读 `references/pedagogical-rubric.md` 对应节，不整文件搬运进上下文；
2. **机器可判项**（M1/M5/M6、B1/B2/B4）：走确定性脚本/结构校验初筛，人复核；
3. **语义判据**（M2/M3/M4、B3 档位、A1–A4）：LLM 初判 + 管家节点裁决，禁造伪机器阈值；
4. **结论输出**：每条判据结论须带「判据编号 + 量规出处节号」，可回溯；
5. **冲突裁决**：本 skill 与 `seven-dimension-rubric.md` 重叠时，按量规 §0 单一源声明取权威源。

## 边界（不做什么）

- 不产出教学内容、不改课件（那是成员职责，本 skill 只判）；
- 不复制量规判据到本文（防止双源漂移）；
- 不引入跨包依赖（与 smart-textbook-team 等无共享判据源，决策④）；
- 量规未定义的判据诉求 → 提案走 Loop A 批次，不在调用中临场造判据。
