## 二、本批实测揪出的真缺陷（独立验证发现，非自述）

1. **【P1】T1b 反向例前提被合法改变（第二次）**：F1 的块级证据层 + `.gates` 路径前缀白名单
   使内置登记里**找不到**"只靠自身登记才存活"的键 ⇒ 动态挑样例退化成 skip。
   修法：改为**自足式合成反例**（隔离副本自造探针键 + 登记，撤登记须转死）。
2. **【P1】链式重建初版误判本包主流读法**：`_section(cfg, "delta_gate")` 的段名以实参传入，
   纯属性链断裂 ⇒ 补节访问器约定与局部变量绑定，弱证据 17 → 4。
3. **【P1】T1b 样例筛选漏查前缀** ⇒ 挑出"去掉登记后仍存活"的样例。
4. **【P2】取证工具本身造假绿**：macOS BSD grep 不支持 BRE `\|` ⇒ 静默返回空，
   差点误报「G1 四断言未落地」。**新增纪律**：取证"搜不到"须用两种工具各验一次。
5. **【P2】测试自身写错**：python-pptx 拒绝 <1 英寸页高；备注标注文案含后缀。
   ⇒ 断言按实际实现改正（**不改实现去迁就测试**）。
