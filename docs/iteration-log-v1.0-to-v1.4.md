### 关键修复

1. **严真奥 vs 屠明熙 医学图像归属**（C1）：明文划界——严真奥只核验"承载的知识点准确性"，屠明熙管视觉规范
2. **路径B移交 schema 对齐**（C2/S1/L3）：字段名严格对齐 teaching-ppt-studio v2.1.0；探测3次失败强制回退路径A
3. **统一回传 schema**（C3）：`{from, stage, artifact, warnings, evidence_used, next_recommendation}`
4. **阶段3并行超时降级**（L1）：单边超时>5min按"教学列/版式列"降级默认安全版式
5. **ReAct 循环硬限**（L2）：单条缺口≤3轮循环；累计≤15轮终止本阶段
6. **任务状态文件 task_state.json**（S2）：长任务断点续传基础设施
7. **工具/通道不可用回退表**（T4）：TeamCreate/SendMessage/Agent/Ima 四通道全覆盖

## v1.3 → v1.4（5 项新 bug 修复）

### RedTeam 对抗扫描新发现

| 攻击 | 描述 | 根因 |
|------|------|------|
| 5 | deviations裁决权越界 | 路径B偏差时郅作基可能自主决定 |
| 2 | pending_items 流转丢失 | 主理人终检项未含"遗留待办转发" |
| 3 | 预取事实过期检测缺 | 阶段1预取事实，阶段2用户改需求时仍沿用 |
| 4 | task_state.json 并发冲突 | 两会话同时跑同一任务会互相覆盖 |
| 1 | 路径A/B决断权模糊 | 郅作基自主选择违反"成员结论为准" |

### 修复

1. **路径决断权属主理人**（next_action 下发）
2. **路径B偏差裁决协议**（deviations 非空→主理人裁决）
3. **pending_items 流转强制**（终检项含"遗留待办"）
4. **预取事实过期校验**（先查 task_state 再决定）
5. **并发会话冲突防护**（task_id 比对+停止推进+报警）

### 回归验证（21/21）
- v1.3.0 16 项 + v1.4.0 5 项 = 21 项全部通过 ✓
- 5页复杂场景端到端（受众/课时/4红线）实测通过 ✓
