### 3.1 域上下文注入（Task #1）

- **注入位置**：装配产物中「角色定义」段**之后**、「任务包」段**之前**，段标题 `==================== 域上下文（v3.17.0 坍缩产物注入） ====================`，结构固定为八段（生效状态 → 域人格 → 内容轴 → 证据两轴 → 取图通道 → 知识库 → 术语 → 红线 → 知识锚点）。
- **内容源**：坍缩产物 JSON 的 `role_persona` / `content_axes` / `evidence_hierarchy` / `image_channel` / `safety_redlines` / `knowledge_bases` / `terminology` / `knowledge_anchor`；域档案 `config/domain-profiles.yaml` 补缺并提供通用兜底段。
- **参数**：`--collapse-artifact <路径>`（显式）/ `--domain-profile <路径>`（默认本包 `config/domain-profiles.yaml`）/ `--run-dir` 与 `--workspace`（自动发现 `_collapse/` 下产物，多个候选取 `confirmed_at` 最新者）。
- **安全语义（实测逐条验证）**：

| 情形 | 装配产物表现 | stderr |
|---|---|---|
| `status=confirmed` 且 `effective=true` | 完整八段域上下文 | 「✅ 坍缩产物已确认生效」 |
| `status != confirmed` 或 `effective != true` | **不注入**域人格 + 「⚠️ 域人格未生效（未确认）」 | 「⚠️ 域人格未生效（未确认）……不注入域人格」 |
| 域档案读不到 / 档案中无该域 | **不注入**域人格 + 「⚠️ 域档案不可用——**本条按通用兜底处理**」 | 「⚠️ 域档案缺失——本条按通用兜底处理」 |
| 无坍缩产物 | **不注入**域人格 + 「⚠️ 未找到坍缩产物」 | 同 |
| 成员在该域绑定为 `domain_neutral` | **不注入**域人格 + 「ℹ️ …`domain_neutral`」 | 同 |

- **严禁静默回落**：域档案缺失时兜底内容取自 `config/domain-profiles.yaml#fallback`（唯一源），回归用例断言产物中**不含** `动物医学` 字样。
