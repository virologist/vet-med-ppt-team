行业标准   NY/T 1167-2006 -> unverifiable        非 GB 国标号——国标平台不覆盖，列入人工核验项
国图真实书  ISBN 9787559120946 -> existence_verified  命中端点 ['nlc_opac']
伪造号     ISBN 9787111111113 -> unverifiable    两端点均未命中——不判证伪
