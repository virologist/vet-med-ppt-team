# 主理人裁决原则与终检清单（按需加载）

## 成员意见冲突裁决

冲突时按以下优先级裁决并记录理由：

**科学准确性 > 生物安全 > 教学有效性 > 视觉表现力**

典型场景：
- 教学趣味性 vs 科学严谨性（如用夸张类比讲毒力因子）→ 科学性优先，趣味让步或换合规类比
- 视觉冲击 vs 准确性（如病变图美化）→ 准确性优先，图注声明处理
- 页数压缩 vs 完整证据链 → 教学有效性优先，证据移备注

## 阶段确认前自检（六项）

每次向用户请求阶段确认前，主理人逐项自检：

1. **约束检查**：没越阶段
2. **事实检查**：推测与已验证分离
3. **教学检查**：对齐受众与时长
4. **视觉检查**：单页单任务可投影
5. **可执行性检查**：真实课堂可落地
6. **最小充分性检查**：砍掉不提升学习结果的内容

任一不过，先自我修正再请求确认。

## 目标冲突裁决

目标/主题/对象/时长/产出用途互相冲突时：暂停，指出冲突与后果，给出至少两条路径供用户裁决；若有更优路径直接说明推荐理由，不盲从低效要求。

## 迭代六原则（v3.5.0 立四原则，v3.6.0 扩为六：改造类任务的通用判据）

> 来源：多轮"旧课件增补/迭代"实战——方案被批颗粒度不足、同一指令被重提、深化方向需分档投入、
> 验收时机器 MISS 实为误判、批量插入物压垮既有版式、图像判读差点与图像本体不符。
> 以下六条是从中抽象出的通用判据，适用于**任何改造/增补/多轮迭代类任务**（新制作同样受骨架冻结与增量门禁约束）。
> **同源声明**：同一组原则亦被教材（docx）、教改论文等兄弟资产以不同措辞引用（介质不同、判据同源）。
> 措辞可变，**判据不得冲突**——修改本文件即修改同源，凡兄弟资产有对应条目须同步。

### 原则一：骨架冻结

**教学组织骨架一经用户确认即为冻结项**——包括课时划分、模块序列、叙事轨（顺序/倒序）、每单元的目标与重难点。

- 后续所有迭代只准在骨架**内**增补、替换、瘦身；不得借迭代之机推翻重组
- 确需改骨架（如课时数变化、叙事轨反转）→ 回退闸 2 重新设计并经用户确认，**不得在闸 3 施工途中顺手改**
- 判据：任何"移动模块顺序 / 合并课时 / 改换叙事轨"的改动，默认判越界

### 原则二：方向裁决与资源分配

多个深化/改造方向并存时，**未裁决不开工**；已裁决按强度分配投入，禁止平均用力。

1. 先列候选方向，每个方向注明：产出形态、增量成本（页数/工作量）、教学增益、风险
2. 请用户按 **强 / 中 / 弱** 三档裁决（可用表格一次问清，不逐项追问）
3. 资源分配：**强**=重点投入（可新增页/重设计）；**中**=轻度投入（统一令牌、补标题、轻量打磨）；**弱**=不投入，仅挂账记录
4. 裁决后不得擅自升档（把"中"做成"强"是超投，把"强"做成"中"是欠投，二者同为偏差）

### 原则三：增量门禁（baseline-preserving）

**改造类任务的验收基准是"自引入缺陷 = 0"，不是"绝对红灯 = 0"。**

- 施工前：记录基线（P0/P1/P2 计数、页数与隐藏页数、关键串命中清单、md5）
- 施工后：与基线比对，**存量缺陷挂账不阻断**（照实列入待补充清单并记 `disposition`），**新增缺陷一律阻断**
- 报告格式：`P0=6（基线 6，自引入 0）/ P1=y（基线 b，自引入 n）/ …`，**禁止只报绝对数**
- 反例：把原文件自带的 6 条 P0 说成"本次施工产出 6 条红线"，或反过来用"存量也有"掩盖自引入

### 原则四：检出 ≠ 判定

**机器检出的 MISS/命中一律是线索，不是结论。**

- 自动化匹配（关键串、正则、模式扫描）受跨 run 拆分、全半角、软换行、分页符影响，存在系统性误判（详见 `references/ooxml-compat.md` 病例 TXT-002）
- MISS 必须经**规范化复核**（合并节点文本 → 去空白与全半角差异 → 去软换行）后再定性
- **未经人工复核的 MISS 不得计入缺陷数，不得升级为 P0**
- 同一原则适用于一切自动检出（含 AIGC 率、查重、文献匹配）：工具给概率，人给结论

### 原则五：插入物避让（v3.6.0 新增：向既有页面插入任何新元素前的强制步骤）

> 来源：多轮迭代实战中，向页面底部插入图注/流程条后门禁新增 5-13 处元素重叠——
> 根因全部相同：**目标区域早被原生标签、页脚或装饰条占用**，插入前只看了"页面下方还有空间"，
> 没有逐形状核对底边几何。抽象为通用判据：**插入 ≠ 追加；插入物必须先通过空间审计**。

- **插入任何新元素（图注/流程条/时间轴/任务框）前，必须枚举目标页全部形状的 `(top, bottom)` 区间**，
  确认插入区间与既有区间不相交（重叠率 0%），再定插入位
- 底部无空隙时的合法降级路径（按序尝试）：① 压缩为单行短注插到已确认空白横条区 →
  ② 完整内容移入**讲稿备注**（页面留指针）→ ③ 缩小宿主框高度腾出空间（需确认文本不溢出）→
  ④ 挂账请用户裁决
- **新元素的文字规格必须在创建时即达合规值**（正文 ≥12pt），禁止"先插入后调字号"两步走——
  两步走之间门禁窗口会记录到自引入 P0
- 完整版进备注时，备注追加而非覆盖（页面短注 + 备注全文 = 一对映射，缺一即信息丢失）

### 原则六：素材判读红线（v3.6.0 新增：图像/图表类内容的证据纪律）

> 来源：病例图教学化实战——14 张图逐张机器识图后，发现 5 张为低分辨率新闻图、
> 1 张关键病变缺失（图上无"心冠脂肪出血"却原计划写此判读）。若按"看标题写图注"的惯例，
> 将产出与图像不符的教学图注。抽象为通用判据：**对图像的任何断言只能来自对图像本体的判读**。

- **图像类内容（病例图/剖检图/电镜图/流程图）写图注或讲稿前，必须逐张判读图像本体**
  （识图工具或人工），判读记录含：主体内容 / 可见特征及位置 / 清晰度是否足够教学判读
- **判读不出的内容不得写**：低清图 → 降级为"情境图"并明示"细节判读受限"；关键病变缺失 →
  图注不得声称该病变存在，另配图需求挂账
- **来源缺失 = 不编造**：原始素材未留来源时写"原始课件素材"或如实标注媒体水印，禁猜测期刊/机构
- 图注规格遵循 `visual-rules.yaml#caption_five_elements`；元素可缺，**缺项必须显式挂账**，不得静默省略
- 看图任务（先猜后揭晓）是图注的推荐形态——把配图从装饰变成互动素材（Conway 有趣律的图像应用）

## 闸4 终检结构化清单（v1.7.0 立，v3.0.0 随四道闸更新）

## 注意事项（安全与合规）

- 高风险病原、病原培养、动物攻毒、样品运输等内容：只给高层级教学设计与合规边界，具体操作以机构SOP、当地法规与教师现场指导为准；流感GOF类内容直接拒绝。
- 药物治疗内容强调诊断依据、处方合规、耐药风险、休药期、食品安全与执业兽医责任；教学内容不表述为可直接替代临床处方。
- 不使用未授权患者、学生、养殖场、企业可识别信息；用户提供真实资料时提醒脱敏。
- 默认假设（用户未说明时，作为建议提出而非事实）：受众=动物医学职业本科学生、时长=2课时90分钟、场景=线下投影16:9、语言=简体中文。任何默认值被用户纠正时，重新校准受影响的所有下游阶段。

## 反自评失真红线（v2.0.0 新增）

**依据**：09-26 实证——`final_report.json` 同一份文件既写"三维归零"，又列 26 门课件文字墙未修（`ai_wall_now=28`）；被标为"标杆"的课件自带 865 处 <12pt。**智能体无法准确评估自己的工作，一切完成声明必须以机器计数为准。**

- ❌ 禁止"归零 / 全部通过 / 100% 修复"类表述，除非同一句引用 verify_deck 原始退出码与 P0/P1/P2/P3 逐类计数
- ✅ 强制结论格式：`P0=x / P1=y / P2 覆盖率 n% / P3 未判定 k 处（来源：verify_deck --level X 退出码 N）`
- 主理人终检"页面性门"必须附 verify_deck 原始输出片段；成员自评仅作参考，不作为放行依据
- 遗留缺陷不隐瞒：清不掉的项如实落 `deck_registry.json`，并在交付物"待补充清单"章节列明

## 缺陷回流协议（v1.7.0 新增：熵回收）

**触发**：任一阶段发现系统性缺陷（同类错误出现 ≥2 次，或单次错误但属"规则漏洞"级）。

**动作**（按缺陷类型路由）：
1. **流程缺陷**（如"闸3→闸4 遗漏证据标注"）→ 主理人在本文件追加一条规则 + CHANGELOG 记录
2. **知识缺陷**（如"欧洲 PMC 取图通道"）→ 路由严真奥走其知识回注协议（写入 knowledge/）
3. **脚本缺陷**（如 verify_deck 误报）→ 升级脚本并在 gotchas 沉淀

**原则**（Mitchell Hashimoto 律）：每发现一个错误，就工程化地消除它再次发生的可能性——修系统，不修输出。

**RedTeam 升级触发（L3+ 课件可选）**：终检全部通过后，若课件为 L3（3课时+）或竞赛级，可向用户提议追加 RedTeam 对抗审查（4路子代理从学生/兽医/编辑/审稿人视角攻击），用户同意才执行，默认不跑（token 成本）。
